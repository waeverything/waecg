# waecg
WAEverything stream graphics using NodeCG

## Requirements
- Node 24
- Git

## Installation
1. Clone this repository
2. Open terminal inside the cloned directory
3. `npm install`
4. `npm run build`

## Running
```bash
npx nodecg start
```

## Updating the bundle
### With Git
1. Open terminal in the `waecg` directory
2. `git pull --rebase`
3. `npm install`
4. `npm run build`

### Without Git
1. Re-download the repository zip from Github
2. Unzip the downloaded file
2. Open terminal inside the unzipped `waecg` directory
3. `npm install`
4. `npm run build`
